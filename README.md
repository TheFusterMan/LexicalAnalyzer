#### 1. «Прикол» со строками и конкатенацией (`+`)
* **В Java:** `"Счет: " + x` превращает число `x` в строку автоматически.
* **В C++:** `"Счет: " + x` — это сложение адреса указателя `const char*` с числом! Код либо выведет мусор из памяти, либо упадет с Segmentation Fault.
* **Как решать:**
  * **Хитрый трюк (лайфхак):** Почти всегда сложение строк делают внутри `System.out.println(...)`. Если при генерации вызова `std::cout` просто заменять бинарный плюс `+` на потоковый вывод `<<`, то никакой `std::to_string` вообще не понадобится!
    * Java: `System.out.println("X = " + x + ";");`
    * C++: `std::cout << "X = " << x << ";" << std::endl;` — **идеально работает само!**
  * Если присваиваем в переменную (`String s = "X: " + x;`), вот тут генератор обязан вызвать `std::to_string(x)`.

#### 2. «Прикол» с типом `byte`
* **В Java:** `byte b = 65; System.out.println(b);` выведет число `65`.
* **В C++:** Если перевести `byte` в `signed char` (как написано у вас в таблице соответствия на стр. 17):
  `signed char b = 65; std::cout << b;` — **выведет букву `'A'`** (так как по таблице ASCII код 65 — это `'A'`).
* **Как решать:** В таблице соответствия для C++ безопаснее сопоставлять `byte` с `int8_t` или `short`, либо при выводе через `cout` приводить его к `(int)b`.

#### 3. «Прикол» с порядком функций (Forward Declaration)
* **В Java:** Методы внутри класса видят друг друга независимо от того, кто выше написан. Метод `main` может спокойно вызывать функцию `calc()`, которая объявлена внизу файла.
* **В C++:** Компилятор читает файл строго сверху вниз! Если `int main()` вызовет функцию, написанную ниже него, C++ выдаст ошибку: `'calc' was not declared in this scope`.
* **Как решать:** Генератор кода должен либо сначала генерировать все пользовательские функции, а `main()` ставить в самый конец, либо сверху генерировать прототипы функций (forward declarations): `int calc();`.
* ✅ Генератор теперь добавляет прототипы функций, включая методы с параметрами-массивами и возвратом массива.

#### 4. «Прикол» с `boolean` в консоли
* **В Java:** `System.out.println(true);` выведет слово `true`.
* **В C++:** `std::cout << true;` по умолчанию **выведет число `1`** (а для `false` выведет `0`).
* ✅ Генератор использует `std::boolalpha` при выводе через `System.out.print` и `System.out.println`, поэтому булевы значения выводятся словами (`true`/`false`).

#### 5. «Прикол» со сдвигом `>>>` (Unsigned Shift)
* **В Java:** Есть два оператора сдвига вправо: `>>` (арифметический) и `>>>` (логический, заполняет нулями).
* **В C++:** Оператора `>>>` физически не существует.
* **Как решать:** В C++ для беззнакового сдвига нужно приводить число к `unsigned`: `((unsigned int)x) >> y`.
* ✅ `>>>` и `>>>=` переводятся через вспомогательные шаблонные функции с приведением к беззнаковому типу и маскированием величины сдвига.

#### 6. «Прикол» с математикой (`Math.sqrt`, `Math.pow`)
* **В Java:** Математика статическая: `Math.pow(2, 3)`, `Math.abs(x)`.
* **В C++:** Библиотека `<cmath>` не имеет класса `Math`. Функции лежат просто в пространстве имен: `std::pow(2, 3)`, `std::abs(x)`.
* **Как решать:** Генератор кода при вызове методов должен проверять: если target начинается с `Math.`, заменять его на `std::` и подключать `#include <cmath>`.
* ✅ Базовое отображение `Math.*` в `std::*` и подключение `<cmath>` добавлены; соответствие имен и перегрузок всех методов Java Math пока не проверяется.

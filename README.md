Токенайзер для лексического анализа кода на Java, семантического анализа и генерации кода на C++

### 📌 Текущий статус проекта
1. **Языковая пара:** Транспилятор из подмножества **Java** в эквивалентный код на **C++**.
2. **Что уже готово (Недели 1-4 по плану):**
   * Разработана математическая модель (грамматика, конечный автомат).
   * Написан **лексический анализатор** (`analizer.py`), работающий на основе регулярных выражений (токенизация).
   * Написан **синтаксический анализатор** (`parser.py`) методом рекурсивного спуска, который успешно строит абстрактное синтаксическое дерево (AST) с использованием `dataclasses` (`ast_structures.py`).
   * Написан **генератор кода** (класс `Generator` в `generator.py`), который принимает `Program` (AST) и рекурсивно собирать строку с кодом на C++ (с учетом `#include <iostream>`, `int main()` и правильных отступов). 
   * Написан **Графический интерфейс (GUI)** с двумя текстовыми панелями (ввод Java, вывод C++) и кнопкой "Транслировать".
